# CLAUDE.md

**ТоргСин** (`goigolden88/Torg_Sin`) — споры и ставки с друзьями «как Polymarket, только свой»: комната по приглашению, события-пул и пари один на один с любым кэфом, исход с гарантом, апелляцией и судом, расчёт «кто кому» в валюте комнаты. Денег не принимает — это записная книжка споров (`docs/01-Проект.md`).

**Стек:** Vite + React + TypeScript (`strict`), хеш-роутинг, обычный CSS, Vitest. Сайт — PWA на GitHub Pages, `base` сборки — `/Torg_Sin/`. Сервер комнат — Cloudflare Worker в `server/` (объект `Room` на комнату, SQLite) над общими правилами `src/rules/`; он — источник истины (Р-01). Запасная обёртка сервера — Node + SQLite в `server/node/` (Р-02). Оба выкатываются сами по слиянию.

Проект вне семьи приложений: ядра `FamilyCore` здесь нет без отдельного решения (Р-08).

## Документы

Лежат в `docs/` и являются источником истины. Код им подчиняется, а не наоборот.

- `01-Проект.md` — зачем, границы, что будет потом, риски
- `02-Архитектура.md` — устройство, модель, правила, крайние случаи, вёрстка, резерв, выкатка
- `03-План.md` — этапы
- `05-Решения.md` — решения «Р-NN» и почему так

## Как работать

1. Сверяйся с `02-Архитектура.md` перед тем, как писать код. Имена полей и типы берутся оттуда; новое — описать там же (шаг 5 исполнителя).
2. Отступление от Архитектуры или решения — вслух и до кода. Молча менять модель или правила нельзя.
3. Решение записывается в `05-Решения.md` сразу. Старые записи не переписываются: отмена — новая запись со ссылкой.

## Правила кода

- **Правила — в `src/rules/`:** чистые функции с тестами (Vitest), без DOM и Cloudflare; ими пользуются и экран, и сервер. Экраны тестами не покрываются
- **Сервер:** логика — без привязки к Cloudflare (как `server/src/http.ts`), тесты с подделками хранилища; `server/src/index.ts` — только привязка. Хранилище — только через `RoomStorage` (Р-02); всё, что есть у Cloudflare-обёртки, должно работать и в Node-обёртке
- **Время — сервера**, хранится в UTC (мс), показывается местное. Сроки закрываются по времени сервера
- **Журнал комнаты только дописывается** (Р-11): отмена и исправление — новая запись, не правка старой
- **Суммы — целыми** в минимальных единицах валюты комнаты; итоги и коэффициенты считаются, не хранятся
- **Протокол:** `PROTOCOL_VERSION` (`src/rules/protocol.ts`) — в каждом ответе и сообщении; несовместимая правка — поднять версию
- К IndexedDB — только через один модуль хранилища; схема версионируется с первого дня, миграции пишутся сразу
- Зависимости — только из списка Р-12. Новая — через решение
- Интерфейс и комментарии на русском, имена в коде на английском

## Правила интерфейса (Р-10)

- **Сначала телефон:** базовый CSS — для узкого экрана, шире — через `min-width` (ступени 600 и 1024 px, `02-Архитектура`, «Вёрстка»). Одна разметка, раскладку меняет CSS
- **Действия — видимыми кнопками:** на телефоне наведения мыши нет; кнопки и поля не ниже 44 px
- **Каждый экран — на двух ширинах, 390 и 1280 px:** снимки обеих — в отчёт PR
- Широкие таблицы на телефоне — карточками; на компьютере Enter отправляет форму, Esc закрывает окно
- **Число — с основанием:** «банк 1 200 ₽, на „да“ 900 — коэффициент 1,33»; ставка и отметка исхода — с подтверждением

## Для конвейера

Агенты конвейера «Штаб» (`goigolden88/Shtab`) работают здесь без человека: берут issue с меткой `готово`, присылают PR, сливает только человек. Правила выше действуют целиком; здесь — только то, что агенту нужно сверх них.

- **Клон:** `npm ci`
- **Проверки перед PR:** `npm test`, `npm run build` (в нём `tsc --noEmit`), `npm run server:check`, `npm run server:build` — итог по коду выхода. Те же гоняет CI на каждый PR («Проверки PR»)
- **Снимки:** `npm run build && npx vite preview`, страница `http://localhost:4173/Torg_Sin/` на 390 и 1280 px (Chrome в прогоне есть)
- **Только через `нужно-решение`:** всё, что меняет хранимые данные (схема IndexedDB и формат записей журнала комнаты после первого релиза); протокол без подъёма версии; новая зависимость сверх Р-12; правка `.github/`, этого файла и `docs/` (кроме описания изменённого в `docs/02-Архитектура.md` — шаг 5 исполнителя, Ш-140 Штаба)
- **Блок «Решение»** в тексте issue (Штаб, Ш-37, Ш-44) — решение владельца, принятое до задачи: перенести его в `docs/05-Решения.md` следующим номером Р-NN, в том же PR, что и код
- **Данные:** реальных комнат в репо нет — он публичный; демо-данные — выдуманные имена и суммы. Пароль компании и ключи — только секретами, не в коде
- **Отчёт** — в описании PR, по шаблону Штаба; `docs/03-План.md` агент не правит
- **После слияния** сайт выкатывается сам (`deploy.yml`) на `https://goigolden88.github.io/Torg_Sin/`; сервер — сам (`server.yml`) на `https://torg-sin.goigolden88.workers.dev/` при правке `server/`, `src/rules/` или зависимостей. Сервер живой ревьюер не видит — в задаче строка «что проверит человек на двух телефонах и компьютере», шаги — в отчёте
